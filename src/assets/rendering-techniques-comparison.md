# Comparación de técnicas de renderizado web

## CSR (Client-Side Rendering)
- Ventajas: Interactividad inmediata, experiencia de usuario fluida.
- Desventajas: Tiempo de carga inicial más largo, SEO más complicado.

## SSR (Server-Side Rendering)
- Ventajas: Mejor SEO, tiempo de carga inicial más rápido.
- Desventajas: Complejidad de implementación, posible latencia en la interactividad.

## Pre-render
- Ventajas: SEO excelente, tiempo de carga muy rápido.
- Desventajas: Dificultad para manejar estados dinámicos, posible complejidad en la gestión de caché.
